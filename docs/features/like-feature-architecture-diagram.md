## 🔄 状态转换图

### 点赞按钮状态机

```
          初始状态
             │
             ↓
      ┌──────────────┐
      │  UNLIKED     │  点击  ┌──────────────┐
      │  🤍 N        │────────→│  LOADING     │
      │  未点赞      │        │  ⏳         │
      └──────────────┘        │  加载中      │
             ↑                └──────┬───────┘
             │                       │
             │失败                  成功
             │                       │
             │                       ↓
             │              ┌──────────────┐
             └──────────────│  LIKED       │
                           │  ❤️ N+1      │
                           │  已点赞      │
                           └──────┬───────┘
                                  │
                                点击
                                  │
                                  ↓
                         ┌──────────────┐
                         │  LOADING     │
                         │  ⏳         │
                         │  加载中      │
                         └──────┬───────┘
                                │
                         ┌──────┴──────┐
                         │             │
                       成功          失败
                         │             │
                         ↓             ↓
                  ┌──────────────┐  保持LIKED
                  │  UNLIKED     │  显示错误
                  │  🤍 N        │
                  └──────────────┘

状态定义:
• UNLIKED: 未点赞 (🤍灰色, 可点击)
• LIKED: 已点赞 (❤️红色, 可点击取消)
• LOADING: 加载中 (⏳, 禁用点击)
```

```
┌────────────────────────────────────────────────────────────────┐

└────────────────────────────────────────────────────────────────┘

Level 1: Memory Cache (内存缓存)
┌─────────────────────────────────┐
│ LikeStateManager.cache (Map)    │

│ 容量: 无限制 (运行时内存)       │
│ 访问速度: < 1ms                 │
│ 命中率: ~90% (热数据)           │
└─────────────┬───────────────────┘
              │ 未命中
              ↓
Level 2: LocalStorage (本地存储)
┌─────────────────────────────────┐
│ localStorage                    │
│ TTL: 永久 (手动清除)            │
│ 容量: 5-10MB                    │

│ 命中率: ~70% (持久化数据)       │
└─────────────┬───────────────────┘
              │ 未命中
              ↓
Level 3: API + Database (远程查询)
┌─────────────────────────────────┐
│ Letmetry Cloud API              │
│ └─ MySQL Database               │
│ TTL: 实时                       │
│ 容量: 无限制                    │
│ 访问速度: 200-500ms             │

缓存更新策略:
• 点赞操作: 立即更新所有层级
• 页面加载: 优先读取缓存，后台刷新
• 定时刷新: 每5分钟检查更新
• 手动刷新: 用户点击刷新按钮
```

## 📊 性能优化对比

### 优化前 vs 优化后

```
┌─────────────────────────────────────────────────────────────────┐
│                     加载100个海报点赞状态                        │
└─────────────────────────────────────────────────────────────────┘

优化前 (逐个查询):
┌───────┐    ┌───────┐    ┌───────┐           ┌───────┐
│ API 1 │───→│ API 2 │───→│ API 3 │─── ... ──→│API 100│
└───────┘    └───────┘    └───────┘           └───────┘
 200ms        200ms        200ms               200ms

总耗时: 100 × 200ms = 20,000ms (20秒) ❌


优化后 (批量查询 + 缓存):
┌───────────────────────┐
│   批量查询 (1次API)    │  → 缓存结果
└───────────────────────┘
         500ms

第一次加载: 500ms ✅
后续加载:  < 5ms (从缓存读取) ✅✅✅

性能提升: 
• 首次加载快 40倍 (20s → 0.5s)
• 缓存命中快 4000倍 (20s → 0.005s)
```
