为什么带孩子来 河南博物院

带孩子逛河南博物院，是把课堂直接搬进郑州的真实地标。河南博物院以中原文化、文物、历史见长，馆里的藏品与空间本身就是最好的亲子教材——比起“看完”，我们更鼓励“观察到”。馆内的镇馆之宝往往是最能抓住孩子注意力的入口，先从一件开始讲起就好。

  • 理由 1：隔着展柜和几千年前的器物对望，是最天然的“为什么”触发点。
  • 理由 2：在真实的历史现场帮孩子建立“时间”的概念，比课本更具体。
  • 理由 3：少即是多：挑 1–2 件展品深挖，比走马观花更有记忆点。

河南博物院 · 镇馆之宝

妇好鸮尊

商代晚期 · 青铜器

1976年安阳殷墟妇好墓出土，通高46.3厘米，鸮（猫头鹰）形青铜盛酒器，中国最早鸟形铜尊之一，河南博物院镇院之宝。

图片：Cangmin / CC BY-SA 4.0, via Wikimedia Commons

莲鹤方壶

春秋中期 · 青铜器

1923年新郑李家楼郑公大墓出土，高117厘米，壶顶莲瓣盛开、立一振翅仙鹤，郭沫若誉其为'时代精神之象征'；河南博物院与故宫各藏一件。

图片：Greg_kf / CC BY 3.0, via Wikimedia Commons

云纹铜禁

春秋中期 · 青铜器

1978年淅川下寺楚墓出土，通高28.8厘米，失蜡法铸造的云纹铜禁（承置酒器的案具），中国首批禁止出境展览文物。

图片：Greg_kf / CC BY-SA 3.0, via Wikimedia Commons
