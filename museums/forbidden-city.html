为什么带孩子来 故宫博物院

带孩子逛故宫博物院，是把课堂直接搬进北京的真实地标。故宫博物院以历史、建筑、文物见长，馆里的藏品与空间本身就是最好的亲子教材——比起“看完”，我们更鼓励“观察到”。馆内的镇馆之宝往往是最能抓住孩子注意力的入口，先从一件开始讲起就好。

  • 理由 1：在真实的历史现场帮孩子建立“时间”的概念，比课本更具体。
  • 理由 2：古建本身就是立体的美学课，屋顶、斗拱、院落都值得抬头看。
  • 理由 3：隔着展柜和几千年前的器物对望，是最天然的“为什么”触发点。

故宫博物院 · 镇馆之宝

清明上河图

北宋 · 书画（风俗长卷）

北宋张择端所作风俗长卷，细致描绘汴京清明时节市井繁华与漕运景象，为中国十大传世名画之一，首批禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

金瓯永固杯

清乾隆 · 金银器（玉杯）

清乾隆御用饮酒金杯，金胎镶嵌珍珠、红蓝宝石，寓意江山永固，为清宫元旦开笔仪式之重器。

图片：CC BY-SA 4.0, via Wikimedia Commons

平复帖

西晋 · 书法（章草）

西晋陆机章草墨迹，为现存最早的名人书法真迹，内容为一封问候友人的书札，首批禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

乾隆田黄三联印

清乾隆 · 玺印（田黄石）

清乾隆帝田黄三联玺，三方印以整块田黄石雕出的石链相连，巧夺天工，首批禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

九龙壁

清乾隆 · 琉璃建筑

故宫珍宝馆内单面琉璃影壁，壁面九条蟠龙戏珠于云水山石之间，为清代琉璃烧造工艺代表作。

图片：CC BY-SA 4.0, via Wikimedia Commons

大禹治水玉山

清乾隆 · 玉器（玉山子）

清乾隆青玉山子，重逾五吨，以宋人《大禹治水图》为稿本于扬州雕成，现存最大的单体玉雕，陈设于宁寿宫乐寿堂。

图片：CC BY-SA 4.0, via Wikimedia Commons
