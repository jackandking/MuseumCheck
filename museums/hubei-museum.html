为什么带孩子来 湖北省博物馆

带孩子逛湖北省博物馆，是把课堂直接搬进武汉的真实地标。湖北省博物馆以历史、音乐、青铜器见长，馆里的藏品与空间本身就是最好的亲子教材——比起“看完”，我们更鼓励“观察到”。馆内的镇馆之宝往往是最能抓住孩子注意力的入口，先从一件开始讲起就好。

  • 理由 1：在真实的历史现场帮孩子建立“时间”的概念，比课本更具体。
  • 理由 2：少即是多：挑 1–2 件展品深挖，比走马观花更有记忆点。
  • 理由 3：提前给孩子一个“小任务”，让观察有目标，逛馆不喊累。

湖北省博物馆 · 镇馆之宝

曾侯乙编钟

战国早期 · 青铜乐器

战国早期曾国国君墓葬出土，65件青铜编钟总重超2.5吨，一钟双音、音域宽广，改写了世界音乐史，首批禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

越王勾践剑

春秋晚期 · 青铜兵器

春秋晚期越王勾践自用青铜剑，剑身满饰菱形暗格花纹，深埋两千余年仍寒光逼人、几无锈蚀，被誉为“天下第一剑”。

图片：CC BY-SA 4.0, via Wikimedia Commons

曾侯乙尊盘

战国早期 · 青铜礼器

战国早期，由尊与盘组成，通体失蜡法铸造的镂空蟠螭纹极尽繁复，是先秦青铜铸造工艺的巅峰之作。

图片：CC BY-SA 4.0, via Wikimedia Commons

云梦睡虎地秦简

秦 · 竹简（法律文献）

秦代竹简，含《秦律十八种》等法律文献，出自基层官吏“喜”的墓葬，是了解秦代制度与日常的一手史料。

图片：CC BY-SA 4.0, via Wikimedia Commons

元青花四爱图梅瓶

元 · 瓷器（青花）

元代青花瓷代表作，腹部绘王羲之爱兰、陶渊明爱菊、周敦颐爱莲、林逋爱梅鹤“四爱图”，2006年出自明郢靖王墓。

图片：CC BY-SA 4.0, via Wikimedia Commons

鹿角立鹤

战国早期 · 青铜（神兽造型）

战国早期曾侯乙墓出土，青铜铸鹤身、鹿角立于鹤首，造型奇特的祥瑞神兽，象征沟通天地。

图片：CC BY-SA 4.0, via Wikimedia Commons
