为什么带孩子来 上海博物馆

带孩子逛上海博物馆，是把课堂直接搬进上海的真实地标。上海博物馆以艺术、文物、收藏见长，馆里的藏品与空间本身就是最好的亲子教材——比起“看完”，我们更鼓励“观察到”。馆内的镇馆之宝往往是最能抓住孩子注意力的入口，先从一件开始讲起就好。

  • 理由 1：真迹面前讲构图与色彩，审美启蒙不用等到长大。
  • 理由 2：隔着展柜和几千年前的器物对望，是最天然的“为什么”触发点。
  • 理由 3：少即是多：挑 1–2 件展品深挖，比走马观花更有记忆点。

上海博物馆 · 镇馆之宝

大克鼎

西周 · 青铜礼器

西周中期青铜礼器，内壁290字铭文记贵族克受周王赏赐而作器，为上博镇馆之宝，与国博大盂鼎并称“海内双鼎”。

图片：CC BY-SA 4.0, via Wikimedia Commons

晋侯稣钟

西周 · 青铜乐器

西周晋侯稣编钟，钟上铭文记晋侯稣随周厉王出征获胜受赏，为上博镇馆之宝，是研究西周史与乐律的稀有实物。

图片：CC BY-SA 4.0, via Wikimedia Commons

商鞅方升

战国 · 量器

战国商鞅变法时制造的标准量器，刻有铭文，为秦国统一度量衡的实物见证，是中国度量衡史的重要物证。

图片：CC BY-SA 4.0, via Wikimedia Commons

王献之鸭头丸帖

东晋 · 书法（行草）

东晋王献之传世行草墨迹，帖文仅“鸭头丸故不佳”等十五字，笔势连绵，为禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

淳化阁帖

北宋 · 法帖（刻帖）

北宋《淳化秘阁法帖》传世最善本（修内司本），汇刻历代名家书迹，素有“法帖之祖”之称。

图片：CC BY-SA 4.0, via Wikimedia Commons

越窑青釉海棠式碗

唐 · 瓷器（越窑青瓷）

唐代越窑青釉碗，海棠式曲线口腹，釉色青润，为越窑秘色瓷代表作，体现唐代越窑素雅之美。

图片：CC BY-SA 4.0, via Wikimedia Commons
