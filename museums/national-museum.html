为什么带孩子来 中国国家博物馆

带孩子逛中国国家博物馆，是把课堂直接搬进北京的真实地标。中国国家博物馆以历史、文化、艺术见长，馆里的藏品与空间本身就是最好的亲子教材——比起“看完”，我们更鼓励“观察到”。馆内的镇馆之宝往往是最能抓住孩子注意力的入口，先从一件开始讲起就好。

  • 理由 1：在真实的历史现场帮孩子建立“时间”的概念，比课本更具体。
  • 理由 2：真迹面前讲构图与色彩，审美启蒙不用等到长大。
  • 理由 3：少即是多：挑 1–2 件展品深挖，比走马观花更有记忆点。

中国国家博物馆 · 镇馆之宝

后母戊鼎

商 · 青铜礼器

商代晚期青铜重器，重逾八百公斤，为现存最大最重的青铜礼器，1939年出土于河南安阳，首批禁止出境展览文物。

图片：CC BY-SA 4.0, via Wikimedia Commons

四羊方尊

商 · 青铜礼器

商代晚期青铜礼器，四角各铸卷角羊首，造型雄奇，为商代青铜铸造工艺的巅峰之作。

图片：CC BY-SA 4.0, via Wikimedia Commons

击鼓说唱俑

东汉 · 陶俑

东汉灰陶俳优俑，左抱扁鼓、右执鼓槌，神情诙谐，为汉代雕塑生动写实的杰出代表。

图片：CC BY-SA 4.0, via Wikimedia Commons

人面鱼纹彩陶盆

新石器（仰韶文化） · 彩陶

仰韶文化半坡类型典型器物，内壁绘人面鱼纹，1955年西安半坡遗址出土，体现先民的图腾与生命观念。

图片：CC BY-SA 4.0, via Wikimedia Commons

大盂鼎

西周 · 青铜礼器

西周康王时期青铜礼器，内壁291字铭文记康王对盂的诰命赏赐，书法浑厚，与上海博物馆大克鼎并称“海内双鼎”。

图片：CC BY-SA 4.0, via Wikimedia Commons

金缕玉衣

西汉 · 葬玉

汉代诸侯王葬服，以金丝缀连玉片而成，徐州狮子山楚王墓出土，体现汉代玉敛葬的等级与礼制。

图片：CC BY-SA 4.0, via Wikimedia Commons
